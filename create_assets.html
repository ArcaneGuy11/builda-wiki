Basic: Create assets or folders

An asset is a combination of textures and various components.

1. Import assets

The blue "1" on the far left of each category's assets section is the entry point for importing assets.

Image: docs/images/create1.jpg

There are four ways to import assets:

Image: docs/images/create2.jpg

1. Draw

Draw your own assets.

2. Import assets

Import assets from your images.

3. Resource Library

The resource library stores all the resources you have created. Assets can be imported into the current project.

4. Asset Store

Purchase resources from other players in the Builda Asset Store.

Note: When others sell assets, they may have some custom components and scripts attached to them. When you buy these assets and import them into your own project, these things will be imported as well. This is why you sometimes find some unfamiliar assets and custom components.

Note: Imported assets that are not original cannot be sold to merchants.

Multiple images for one asset

The same asset can have multiple images, which can save the number of assets you need to create.

For example, if there are many different types of towers, you can create only one tower asset and put the other types in its textures, avoiding the need to create a bunch of separate tower assets.

Image: docs/images/create3.jpg

2. Edit assets

Here we first understand two concepts.

Image: docs/images/create4.jpg

The asset itself

The asset itself refers to the asset in the Asset Store section of the asset panel.

Example of a resource

A resource instance is an asset that has been dragged onto the map.

Image: docs/images/create5.jpg

Editing an asset instance

When we edit an asset instance, it will not affect other instances or the original asset.

When you select "Apply to original", the original asset will be overwritten by the current asset instance, but other existing instances on the map will not be affected.

Image: docs/images/create6.jpg

When you select "Save new assets", the current asset instance will be saved as a new asset in the asset panel.

Editing the original asset

Enter the asset editing interface to modify the asset itself. This will not affect other instances already on the map.

Image: docs/images/create7.jpg

3. Delete assets

Delete an asset

To delete an asset, click the gear icon and then click Delete.

Image: docs/images/create8.jpg

Delete an asset in the library

Currently, assets in the asset library cannot be deleted.

Image: docs/images/create9.jpg

4. Folder assets

1. Create a folder

As our resources accumulate, the resource section can become cluttered. Creating folders can help organize and tidy up existing resources.

Image: docs/images/create10.jpg

2. Move assets

  1. Click the gear icon and select "Move to".
  2. Long-press the asset, then drag and drop it directly into the folder.

5. Copy assets

Copying an asset will create a copy of the current asset.

Image: docs/images/create11.jpg

When copying assets, you can change the type of the current asset.

Note: The asset type cannot be changed when copying a Tiles asset.

Image: docs/images/create12.jpg

6. Asset Image Folder

When a resource has multiple images or animations, the resource will be stored as a folder in the resource library.

Image: docs/images/create13.jpg

7. Add components to the images

Adding components can give assets functionality, but note that different types of assets can have different components added.
